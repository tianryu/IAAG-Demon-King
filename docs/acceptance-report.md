## 浏览器实测

使用 Codex 内置 Chromium 浏览器，实际点击迎敌、升级、关闭重开、胜利返回、失败整军，并通过 WASD 验证纵向移动。测试场景为独立内存存档；生产构建不含 QA 面板。最终发布版浏览器错误和警告日志为空。

测试期间满级场景浏览器显示约 129 至 134 FPS。该数值只代表当前 Windows 桌面环境，不代表手机性能，也不作为移动端性能验收。手机真机、长时间发热和多小时经济平衡仍需试玩验证。
